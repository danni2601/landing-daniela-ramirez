# Mi Landing de CV
**Arquitectura de información, diseño y contenido — en lenguaje natural**

## 1. Estructura general y navegación
El portafolio estará diseñado como una página web de tipo *one page*, con una navegación sencilla, intuitiva y completamente responsiva. En la parte superior contará con un menú fijo que incluirá el logotipo y nombre de **Tow Studios**, así como enlaces a cada una de las secciones.

La página presentará la información en un orden estratégico, priorizando los aspectos más relevantes para posibles clientes y empleadores: presentación del estudio, formación académica, experiencia profesional, perfil personal, habilidades y contacto.

También incluirá un botón para alternar entre el tema claro y oscuro. En tabletas y dispositivos móviles, el menú de navegación se transformará en un botón de hamburguesa que desplegará las diferentes secciones.

Todo el sitio seguirá mi sistema de diseño, manteniendo una identidad visual coherente, una navegación accesible y una experiencia adaptable a distintos dispositivos.
